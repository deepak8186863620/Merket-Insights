Abstract

Stock market research is traditionally fragmented across isolated platforms: technical charting systems, fundamental screeners, news portals, and generic AI chatbots. Professional market terminals like Bloomberg resolve this fragmentation but remain economically inaccessible to retail investors, students, and independent analysts. Furthermore, generic LLMs suffer from knowledge cutoffs and lack access to real-time market data.

To solve this challenge, this project presents MarketInsight v2.0, a full-stack quantitative financial intelligence platform. MarketInsight combines a LangGraph ReAct AI agent powered by Google Gemini with 16 real-time Yahoo Finance execution tools, a FastAPI asynchronous streaming backend with Server-Sent Events (SSE), and a React 18 + TypeScript Quant Workstation styled in an institutional dark aesthetic. The system features custom SVG charts with hover crosshairs, live DCF intrinsic valuation models with dual sensitivity sliders, sector treemap heatmaps, sparkline watchlists, and native browser voice transcription.

3.3 Quantitative Models

A. Relative Strength Index (RSI)

RSI = 100 - [ 100 / (1 + RS) ]
where RS = Average Gain (14 periods) / Average Loss (14 periods)
Signals: RSI < 30 (OVERSOLD / BUY) • RSI > 70 (OVERBOUGHT / SELL)

B. Discounted Cash Flow (DCF) Intrinsic Value

PV_CashFlows = Σ [ FCF_0 * (1 + g)^t / (1 + r)^t ] for t = 1 to 5
Terminal_Value = [ FCF_5 * (1 + 0.03) ] / (r - 0.03)
Intrinsic_Value = PV_CashFlows + [ Terminal_Value / (1 + r)^5 ]
Margin_of_Safety = [ (Intrinsic_Value - Current_Price) / Current_Price ] * 100%

Chapter 4 • Implementation & Results

4.1 Core Backend SSE Streaming (main.py)

@app.post("/api/chat")
async def chat_endpoint(request: ChatRequest):
    async def event_generator():
        inputs = {"messages": [HumanMessage(content=request.message)]}
        async for chunk in agent_executor.astream(inputs, stream_mode="messages"):
            message = chunk[0] if isinstance(chunk, tuple) else chunk
            # Filter internal ToolMessages from leaking into chat view
            if getattr(message, "type", None) == "tool" or message.__class__.__name__ == "ToolMessage":
                continue
            text = extract_text(getattr(message, "content", ""))
            if text:
                yield f"data: {json.dumps({'text': text})}\n\n"
        yield f"data: {json.dumps({'done': True})}\n\n"
    return StreamingResponse(event_generator(), media_type="text/event-stream")
