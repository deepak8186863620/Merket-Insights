🚀 1. FastAPI & Backend

Why did you choose FastAPI over Flask or Django?

FastAPI supports async natively, which is critical for streaming responses. It auto-generates Swagger docs, has built-in Pydantic validation, and is significantly faster than Flask. For a streaming AI app, async was non-negotiable.

How does streaming work in your backend?

I use FastAPI's StreamingResponse with media_type='text/event-stream'. The agent yields tokens one by one using LangGraph's stream_mode='messages'. Headers cache-control: no-cache and connection: keep-alive keep the connection open (SSE).

What is CORS and why did you add it?

CORS (Cross-Origin Resource Sharing) is a browser security policy that blocks requests from a different origin. My frontend on port 3000 and backend on port 8000 are different origins, so I added FastAPI's CORSMiddleware to allow cross-origin calls.

What is Pydantic and how did you use it?

Pydantic is a data validation library. I used it to define the RequestObject model in config/config.py, which validates incoming JSON request bodies automatically — FastAPI raises a 422 error if the payload doesn't match the schema.

🤖 2. LangChain / LangGraph (AI Agent)

What is an AI Agent? How is it different from just calling ChatGPT?

A plain ChatGPT call returns a static response from training data. An agent has a reasoning loop — it decides whether to call a tool, calls it, gets real data, then generates an answer. My agent uses LangGraph's ReAct pattern: Reason → Act → Observe → Repeat.

How does the agent decide which tool to use?

The LLM is given descriptions of all 16 tools. Based on the user query, it selects the right tool(s) via function-calling. For example, "What are TCS dividends?" → agent calls get_dividends("TCS") → returns live Yahoo Finance data.

What is MemorySaver and why did you use it?

MemorySaver is LangGraph's in-memory checkpointer. It persists conversation state between messages using a thread_id, giving the agent multi-turn memory — it remembers context from earlier in the conversation.

What is thread_id used for?

Each chat session has a unique thread_id. LangGraph uses it to isolate conversation history per user, so multiple users can chat simultaneously without their sessions mixing.

What is the system prompt doing in your code?

The system prompt instructs the agent to always prefer tools over guessing: "If an appropriate tool exists, you must use it before answering. Never guess, assume, or fabricate any financial data." This prevents hallucination of financial figures.

📈 3. Yahoo Finance / Real Data

Is the data real-time or delayed?

Yahoo Finance provides data that is typically 15-20 minutes delayed for live price quotes (free tier). Historical data, financial statements, and company info are accurate and current. For true tick-by-tick data, a paid feed like Bloomberg or Alpaca would be needed.

What happens if Yahoo Finance is down or rate-limits you?

Every tool has a try/except block. If the call fails, it returns a descriptive error string which the agent includes in its response gracefully. Errors are also logged with timestamps via a custom logger.

How does the get_ticker tool work?

It calls Yahoo Finance's search API: https://query2.finance.yahoo.com/v1/finance/search?q={company_name}, parses the JSON, and returns the first matching ticker symbol. This lets users say "Reliance" instead of needing to know "RELIANCE.NS".

⚛️ 4. Frontend (React / Vite / TypeScript)

Why Vite over Create React App?

Vite uses native ES modules and is dramatically faster — instant HMR (Hot Module Replacement). CRA is now deprecated. Vite also has first-class TypeScript support and a better plugin ecosystem.

What is import.meta.env in Vite?

Vite's way of exposing environment variables at build time. Variables prefixed with VITE_ in .env files are injected into the client bundle. Dev mode reads from .env, production reads from .env.production.

How does the frontend handle streaming responses?

The @thesysai/genui-sdk C1Chat component handles SSE natively. It connects to /api/chat and renders tokens as they arrive, producing the typewriter streaming effect in the UI.

☁️ 5. Deployment

Where is the backend deployed and how?

The backend is deployed on Render. The render.yaml file defines the service — the start command (python main.py), environment, and build steps. Render auto-deploys on every push to the main branch.

Where is the frontend deployed?

The frontend is deployed on Vercel, which is optimized for Vite/React. The vercel.json config rewrites all routes to index.html so React's client-side routing works correctly.

How do you manage secrets and API keys?

API keys are stored in .env files locally and set as environment variables on Render/Vercel — never hardcoded in source code. The .gitignore excludes .env from GitHub.

🔍 6. Observability (Langfuse)

What is Langfuse and why did you use it?

Langfuse is an open-source LLM observability platform. It traces every request — recording the input prompt, which tools were called, latency, and the final output. Critical for debugging agent behaviour in production.

What is a Span vs a Generation in Langfuse?

A Span is a generic unit of work — I wrap the entire HTTP request in one. A Generation is LLM-specific — it records model name, input/output, and token usage. Generations are nested inside Spans to create a trace hierarchy.

🏗️ 7. System Design

How would you scale this for 10,000 concurrent users?

1) Replace MemorySaver with Redis for distributed session state. 2) Add a message queue (Celery + Redis) for request bursts. 3) Horizontal scaling behind a load balancer on Render/AWS. 4) Cache frequent queries with Redis TTL — company info doesn't change every second.

What are the current limitations?

1) MemorySaver is in-memory — restarts wipe conversation history. 2) Yahoo Finance rate limits can cause failures under heavy load. 3) No authentication — anyone can call the API. 4) OpenAI API latency adds response time.

How would you add authentication?

Add JWT-based auth using FastAPI's dependency injection. Each request would pass a Bearer token in the Authorization header. The backend would validate it before processing, and the thread_id could be derived from the user's ID instead of a random value.
