\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

\begin{mdframed}[linecolor=cbitred,linewidth=1.5pt,leftmargin=0,rightmargin=0,
  innerleftmargin=12pt,innerrightmargin=12pt,innertopmargin=12pt,innerbottommargin=12pt]
Stock market analysis is traditionally fragmented across disparate platforms: charting utilities, fundamental balance sheet screeners, financial news aggregators, and generic conversational AI assistants. Commercial market terminals like Bloomberg and Refinitiv bridge this gap but are economically inaccessible to retail investors, students, and independent analysts due to high subscription costs. Conversely, modern Large Language Models (LLMs) suffer from static training cutoffs, lack real-time market data access, and cannot execute deterministic quantitative computations such as live Relative Strength Index (RSI) or Discounted Cash Flow (DCF) modeling.

To resolve these challenges, this project presents \textbf{MarketInsight v2.0}, an institutional-grade, full-stack quantitative stock market intelligence platform. MarketInsight pairs a \textbf{LangGraph ReAct AI Agent} powered by \textbf{Google Gemini} with \textbf{16 real-time Yahoo Finance execution tools}, a high-throughput \textbf{FastAPI async backend} with Server-Sent Events (SSE) streaming, and an interactive \textbf{React 18 + TypeScript} Bloomberg-inspired Quant Workstation. 

Key technical contributions include:
\begin{itemize}[leftmargin=*]
  \item A ReAct agent architecture capable of multi-step autonomous tool chaining across real-time prices, historical OHLCV data, analyst consensus, cash flow statements, and options chains.
  \item An SSE streaming parser resolving Gemini's structured array content format alongside a deterministic ToolMessage filter that prevents raw API payloads from leaking into user UI tokens.
  \item An interactive DCF Valuation Simulator running live free cash flow calculations with dynamic user-controlled WACC and growth-rate sensitivity sliders.
  \item A zero-dependency SVG Chart Studio featuring pixel-perfect hover crosshairs, volume distributions, and algorithmic RSI / SMA-20 / SMA-50 technical overlays.
  \item Integrated market treemap heatmaps, sparkline watchlists, two-asset duel arenas, and native voice-driven queries using the browser Web Speech API.
\end{itemize}
All modules are deployed, fully verified, and open-sourced under an MIT license.
\end{mdframed}

\chapter{Introduction}

\section{Brief Description About the Project}

The financial market is a complex, high-velocity domain where timely access to accurate information is the single largest determinant of decision-making quality. \textbf{MarketInsight} is an end-to-end quantitative financial intelligence workstation designed to synthesize live market data, algorithmic technical indicators, fundamental valuation models, and artificial intelligence into a cohesive, user-centric web experience.

Traditional financial software typically forces users into severe tradeoffs. Desktop platforms such as Bloomberg Terminal or FactSet offer exhaustive depth but cost upwards of \$24,000 annually. On the other end, free web applications segment workflows into silos: TradingView handles charting, Screener.in hosts fundamental ratios, and ChatGPT or Gemini answers conversational queries based on outdated training snapshots. MarketInsight removes this fragmentation by establishing an autonomous agent bridge between real-time financial APIs and generative language models.

\section{Motivation}

Retail investors and students face three structural barriers when researching equities:
\begin{enumerate}[leftmargin=*,label=\textbf{\arabic*.}]
  \item \textbf{Information Asymmetry:} Institutional hedge funds deploy automated scrapers, quantitative models, and low-latency API connections. Retail investors frequently rely on delayed quotes and social media sentiment.
  \item \textbf{Tool Dispersal:} Analyzing a single stock like Apple or Tata Motors requires checking a chart on one site, financial statements on another, latest news on a third, and running valuation formulas in an Excel spreadsheet.
  \item \textbf{LLM Hallucinations in Finance:} Standard LLMs fail when asked ``What is the current P/E of TCS?'' because they either hallucinate outdated values or explicitly state they lack real-time access. Equipping an LLM with deterministic tool execution capabilities eliminates this fundamental flaw.
\end{enumerate}

\section{Problem Statement}

To design and implement a real-time, AI-driven quantitative stock market intelligence platform that integrates an autonomous ReAct agent with 16 live financial tools, streams natural-language financial intelligence via Server-Sent Events, computes quantitative technical indicators and intrinsic valuations, and presents the results through a modern, responsive Quant Workstation UI.

\begin{enumerate}[leftmargin=*,label=\textbf{\arabic*.}]
  \item \textbf{Autonomous Tool-Calling Agent:} Develop a LangGraph ReAct agent that parses user queries, autonomously identifies required financial data, and executes appropriate tools via Yahoo Finance.
  \item \textbf{16 Specialized Financial Tools:} Implement deterministic Python tools covering live price discovery, company profiling, historical OHLCV data, financial statements (Income, Balance Sheet, Cash Flow), analyst recommendations, dividend yields, options chains, insider activity, and sector comparisons.

  \item \textbf{Professional Quant Workstation:} Engineer a React 18 + TypeScript frontend styled in a Bloomberg-dark institutional aesthetic, featuring custom SVG charting with hover crosshairs, treemap heatmaps, live watchlists, side-by-side asset duels, and browser-native voice transcription.
\end{enumerate}

\section{Agentic ReAct Execution Loop}

The cognitive flow follows the formal ReAct (Reasoning and Acting) paradigm:
\begin{enumerate}[leftmargin=*,label=\textbf{\arabic*.}]
  \item \textbf{Input Parsing:} The user enters a natural-language query regarding equity valuation or comparisons.
  \item \textbf{Thought Formulation:} Gemini evaluates the query against registered tool schemas and determines the required data sources.
  \item \textbf{Action Execution:} The agent calls specific financial tools such as quote discovery, cash flow extraction, or historical pricing.
  \item \textbf{Observation Ingestion:} Tool execution payloads are fed back into the context graph.
  \item \textbf{Synthesis \& Streaming:} Gemini compiles a cohesive analysis, streaming output tokens through the FastAPI SSE pipeline while the backend automatically attaches audit trail badges.
\end{enumerate}

\section{Quantitative Mathematical Formulations}

\subsection{Relative Strength Index (RSI)}
The Relative Strength Index evaluates momentum over a standard 14-period lookback window:
\begin{equation}
  RSI = 100 - \left( \frac{100}{1 + RS} \right)
\end{equation}
where Relative Strength ($RS$) is the ratio of smoothed average gain to smoothed average loss:
\begin{equation}
  RS = \frac{\text{Average Gain}_{14}}{\text{Average Loss}_{14}}
\end{equation}
\textbf{Decision Thresholds:}
\begin{itemize}[leftmargin=*]
  \item $RSI < 30$: \textbf{Oversold} condition (Bullish reversal signal).
  \item $30 \le RSI \le 70$: \textbf{Neutral} zone.
  \item $RSI > 70$: \textbf{Overbought} condition (Bearish correction risk).
\end{itemize}

\subsection{Discounted Cash Flow (DCF) Intrinsic Valuation}
Intrinsic equity value is modeled by projecting Free Cash Flow ($FCF$) across a 5-year forecast horizon and discounting at the Weighted Average Cost of Capital ($WACC$ or $r$):
\begin{equation}
  \text{PV of Explicit Cash Flows} = \sum_{t=1}^{5} \frac{FCF_0 \cdot (1 + g)^t}{(1 + r)^t}
\end{equation}
where $g$ is the projected annual cash flow growth rate. Terminal Value ($TV$) assumes a perpetual growth rate $g_T = 3\%$:
\begin{equation}
  TV = \frac{FCF_5 \cdot (1 + g_T)}{r - g_T}
\end{equation}
Discounting the Terminal Value back to present value gives:
\begin{equation}
  \text{Intrinsic Market Value} = \sum_{t=1}^{5} \frac{FCF_t}{(1 + r)^t} + \frac{TV}{(1 + r)^5}
\end{equation}
Dividing by outstanding shares yields Intrinsic Value Per Share, compared against Current Price to derive the \textbf{Margin of Safety}:
\begin{equation}
  \text{Margin of Safety} = \left( \frac{\text{Intrinsic Value} - \text{Current Price}}{\text{Current Price}} \right) \times 100\%
\end{equation}

\subsection{Simple Moving Averages (SMA)}
\begin{equation}
  SMA_k = \frac{1}{k} \sum_{i=0}^{k-1} P_{t-i} \quad \text{for } k \in \{20, 50\}
\end{equation}
A crossover where $SMA_{20} > SMA_{50}$ confirms a \textbf{Golden Cross} (bullish breakout), whereas $SMA_{20} < SMA_{50}$ indicates a \textbf{Death Cross}.

\chapter{Implementation \& Results}

\section{System Workflow Description}

The MarketInsight platform implementation consists of four coordinated subsystems:
\begin{enumerate}[leftmargin=*,label=\textbf{\arabic*.}]
  \item \textbf{Asynchronous Streaming Engine:} The FastAPI backend receives requests at the chat endpoint and invokes the LangGraph agent stream. As chunks arrive, a dedicated filtering function intercepts internal tool execution messages, preventing raw API outputs from reaching the user interface while streaming polished analytical sentences via Server-Sent Events.
  \item \textbf{Polymorphic Content Handler:} A dedicated parsing routine resolves Gemini's structured response types, validating and extracting text regardless of whether the token is emitted as a string, a dictionary, or a structured array block.
  \item \textbf{Multi-Tier Price Discovery Pipeline:} The price retrieval tool employs a three-tier fallback architecture: querying the lightweight fast-info quote stream first, inspecting the general company profile dictionary second, and retrieving the latest historical daily close third.
  \item \textbf{Custom SVG Charting Engine:} Rather than relying on external charting libraries, the React frontend renders mathematical SVG paths, computing relative coordinate offsets, dynamic price grids, candlestick wicks and bodies, and interactive hover crosshairs directly in the DOM.
\end{enumerate}

\chapter{Challenges Faced}

Developing MarketInsight required overcoming several critical engineering and architectural challenges across AI streaming, API deprecations, rate limiting, and mathematical modeling:

\begin{enumerate}[leftmargin=*,label=\textbf{\arabic*.}]
  \item \textbf{LLM Deprecation and High-Demand HTTP 503 Errors:}\\
  Initially, the agent was configured using \texttt{gemini-2.0-flash} and \texttt{gemini-3.8-flash}. During development, older endpoints were retired (triggering HTTP 404 NOT FOUND), while newer preview models intermittently returned HTTP 503 SERVICE UNAVAILABLE during peak hours. \\
  \textbf{Solution:} Conducted systematic benchmark testing across all current Gemini endpoints, establishing that \texttt{gemini-flash-lite-latest} provides guaranteed availability, minimal latency, and full support for LangChain ReAct function calling.

  \vspace{0.4cm}

  \item \textbf{Gemini Polymorphic Streaming Content Format:}\\
  Standard LangChain message tokens typically present content as a plain UTF-8 string. However, Gemini's streaming chunk generator returns structured lists of JSON dictionaries. Passing these raw structures directly to the client resulted in empty string emissions or frontend JSON serialization crashes. \\
  \textbf{Solution:} Engineered a recursive content parser in \texttt{main.py} that validates and normalizes all incoming payload variants into clean strings before SSE packaging.

  \vspace{0.4cm}

  \item \textbf{Tool Execution Leaks in User Output Tokens:}\\
  When LangGraph executes external tools (e.g., querying Yahoo Finance), intermediate tool execution chunks are broadcast across the event stream. This resulted in raw ticker queries and intermediate price numbers leaking into user chat bubbles prior to the final conversational answer. \\
  \textbf{Solution:} Implemented a strict type inspection filter in the async generator that discards any chunk matching the tool execution message signature, preserving only human-readable assistant tokens while independently recording invoked tool names for audit badges.

  \vspace{0.4cm}

  \item \textbf{Yahoo Finance HTTP 429 Rate Limiting:}\\
  Frequent programmatic requests to Yahoo Finance ticker lookup endpoints triggered HTTP 429 (Too Many Requests) errors due to automated scraper detection. \\
  \textbf{Solution:} Configured custom browser-emulating request headers and converted price discovery to query the fast-info last price attribute, a dedicated lightweight endpoint with significantly higher rate allowances.
\end{enumerate}

\chapter{Scope of the Project}

\section{In-Scope Functionality}

\begin{itemize}[leftmargin=*,label=$\bullet$]
  \item \textbf{Autonomous Financial AI Agent:} Natural-language understanding paired with dynamic ReAct execution across 16 real-time financial tools.
  \item \textbf{High-Speed SSE Streaming:} Token-by-token response delivery ensuring sub-second visual responsiveness.
  \item \textbf{Transparent Audit Badging:} Explicit visual confirmation in the UI indicating which tools were invoked to formulate each answer.
  \item \textbf{Zero-Dependency Technical Charting:} Interactive candlestick and line charting with custom SVG rendering and hover crosshairs.
  \item \textbf{Fundamental Quantitative Models:} Automated computation of RSI, SMA-20, SMA-50, and Discounted Cash Flow valuation.
  \item \textbf{Market Treemap Heatmap:} Visualizing sector-level market performance with size weighted by market capitalization.
  \item \textbf{Native Voice Input:} Hands-free spoken query submission powered by browser-level Web Speech synthesis.
\end{itemize}

\section{Future Scope and Extensibility}

\begin{itemize}[leftmargin=*,label=$\bullet$]
  \item \textbf{WebSocket Price Feeds:} Transitioning from periodic HTTP polling to continuous WebSocket streams for sub-second quote updates.
  \item \textbf{Personalized Portfolio Tracking:} Integration with database systems to allow authenticated users to log buy/sell transactions and track unrealized profit/loss.
  \item \textbf{Options Greeks Calculator:} Implementation of Black-Scholes pricing models to compute live Delta, Gamma, Theta, and Vega across options chains.
  \item \textbf{Multi-Model LLM Routing:} Enabling users to dynamically toggle between Google Gemini, Anthropic Claude, and OpenAI models.
  \item \textbf{Earnings Call Audio Sentiment:} Utilizing speech-to-text and sentiment analysis to score executive commentary during quarterly earnings calls.
\end{itemize}

\chapter{Conclusion}

\begin{mdframed}[linecolor=cbitred,linewidth=1.5pt,
  innerleftmargin=14pt,innerrightmargin=14pt,
  innertopmargin=14pt,innerbottommargin=14pt]
\textbf{MarketInsight v2.0} successfully demonstrates the potential of combining autonomous Agentic AI with real-time financial data engineering and interactive quantitative web interfaces. By deploying a LangGraph ReAct agent powered by Google Gemini and backed by 16 live Yahoo Finance tools, the platform bridges the divide between static generative language models and dynamic financial markets.
\end{mdframed}

\vspace{0.8cm}

The system resolves the critical issues of information asymmetry, tool fragmentation, and AI hallucinations for retail investors and academic researchers. Its high-throughput asynchronous backend, robust Server-Sent Events streaming engine, custom SVG charting studio, and interactive DCF simulator provide a comprehensive suite of analytical instruments within an institutional Bloomberg-inspired workstation interface.

The project reinforces essential software engineering paradigms: asynchronous API architecture, robust error-handling pipelines, stateful cyclic agent graph design, and modern component-driven frontend architecture. MarketInsight stands as a complete, production-verified, and open-source contribution to modern financial technology.
